Contexte

Le Problème du Coach Sportif

  • Manque d'outils IA dédiés au métier du coaching sportif

02 / 14

Vision

Un Assistant IA taillé pour le Coaching

Gymshark Sync est un assistant IA interne conçu pour libérer le coach des tâches chronophages. Grâce à un LLM local (Ollama), il dialogue en langage naturel pour organiser les séances, générer des synthèses, planifier les actions et automatiser les workflows.

L'objectif : recentrer le coach sur l'essentiel — l'humain et la performance — pendant que l'IA gère la logistique.

Technologies

Stack Technique

  • Frontend : HTML5, CSS3 (variables, grid, flexbox), JavaScript vanilla ES2020+
  • Backend : Node.js, Express 5.2, architecture ESM (modules ES6)
  • LLM : Ollama (modèle phi3:mini par défaut) — exécution locale, zero latence cloud
  • Communication : SSE (Server-Sent Events) pour le streaming temps réel
  • Persistance : Fichier JSON local pour les conversations
  • API Docs : Swagger UI + OpenAPI 3 sur /api/docs
05 / 14

Architecture

Architecture Globale

Frontend SPA HTML · CSS · JS
→
Backend API Express 5.2 · ESM
↔
Ollama LLM phi3:mini · local
↓
Stockage JSON · Fichier local

Le frontend communique avec le backend via API REST + SSE. Le backend relaie les requêtes au LLM local (Ollama) et streame la réponse. Les conversations sont persistées en JSON.

08 / 14

Technique

Streaming SSE en Temps Réel

// POST /api/chat — Le backend streame la réponse du LLM POST /api/chat Content-Type: application/json // Requête { "message": "Planifie ma semaine d'entraînement" } // Réponse SSE (text/event-stream) data: { "type": "meta", "conversationId": "conv_123" } data: { "type": "chunk", "content": "Voici" } data: { "type": "chunk", "content": " votre" } data: [DONE]

Chaque token est transmis instantanément au frontend via SSE — l'utilisateur voit la réponse se construire en direct.

Intelligence

Système de Prompts

  • System Prompt dédié au coaching sportif — contexte métier permanent
  • Chargé depuis un fichier texte, rechargé automatiquement si modifié (cache mtime)
  • Historique de conversation conservé sur les 8 derniers tours (MAX_HISTORY_TURNS)
  • Édition de messages : possibilité de modifier une question et régénérer la réponse

Données

Persistance & Stockage

  • Stockage fichier JSON (data/conversations.json) — simple, fiable, portable
